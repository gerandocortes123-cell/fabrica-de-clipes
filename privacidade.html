Política de Privacidade

Fábrica de Clipes · Última atualização: 18 de novembro de 2026 · Voltar à página inicial

1. Quem somos

A Fábrica de Clipes é um aplicativo pessoal, executado localmente no computador do próprio usuário. Não existe servidor da Fábrica de Clipes que receba dados de usuários.

2. Dados acessados pelas APIs do Google

Quando o usuário conecta a conta do YouTube, o aplicativo recebe do Google um token de acesso com permissão para:

  • Enviar vídeos ao canal do próprio usuário (youtube.upload);
  • Ler o nome do canal e o estado dos vídeos enviados pelo aplicativo (youtube.readonly).

O aplicativo não lê vídeos, comentários, estatísticas nem dados de outras pessoas.

3. Como os dados são usados e guardados

O token é usado somente para enviar os vídeos que o usuário decidiu publicar e para confirmar a conexão. Ele é guardado no próprio computador do usuário, criptografado com a proteção do Windows, e nunca é enviado a terceiros, vendido, compartilhado ou usado para publicidade.

4. Uso Limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google respeitarão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo também cumpre os Termos de Serviço do YouTube e a Política de Privacidade do Google.

5. Como revogar o acesso e apagar os dados

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions ou clicando em “Desconectar” no próprio aplicativo, o que apaga o token guardado no computador. Os vídeos já publicados continuam no canal do usuário e só são removidos por ele no YouTube Studio.
